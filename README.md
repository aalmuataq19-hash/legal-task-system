# ⚖️ نظام إدارة المهام القانونية

نظام لتوزيع المهام القانونية ومتابعتها بين مدير المكتب والموظفين، بواجهة عربية تعمل على الجوال والكمبيوتر.

**الرابط:** https://aalmuataq19-hash.github.io/legal-task-system/

## المميزات

- دخول آمن لكل شخص بحسابه (مدير / موظف) مع خيار «تذكرني».
- المدير يضيف الموظفين ويوزع المهام ويعدّلها ويحذفها.
- الموظف يرى مهامه فقط ويغيّر حالتها (قيد الانتظار / قيد التنفيذ / منجزة).
- تلوين المهام حسب الموعد: أحمر للمتأخرة، وأصفر لما بقي عليه أقل من 24 ساعة، وأخضر للمنجزة.
- التواريخ بالميلادي مع الوقت، وتحتها التاريخ الهجري.
- بحث وتصفية (حسب الحالة، والمتأخرة، والموظف).
- لوحة رئيسية بالإحصائيات والمهام العاجلة وتوزيع العمل على الفريق.
- شعار المكتب واسمه يظهران في النظام وصفحة الدخول (اختياري).
- البيانات محفوظة في قاعدة بيانات Supabase ومشتركة بين جميع الأجهزة.

## التشغيل لأول مرة

1. افتح رابط الموقع، وستظهر صفحة «ربط النظام بقاعدة بيانات مجانية».
2. اتبع الخطوات الظاهرة: أنشئ مشروعاً مجانياً في [Supabase](https://supabase.com)، ثم انسخ كود الإعداد وشغّله في SQL Editor، ثم الصق رابط المشروع والمفتاح العام واضغط «اختبار الاتصال».
3. ضع الرابط والمفتاح في الملف `public/config.json`:
   ```json
   {
     "supabaseUrl": "https://xxxx.supabase.co",
     "supabaseKey": "sb_publishable_..."
   }
   ```
   بعد حفظ الملف يُنشر الموقع تلقائياً خلال دقيقتين تقريباً.
4. افتح الرابط وأنشئ حساب المدير، ثم أضف الموظفين من صفحة «الموظفون».

> المفتاح العام (publishable / anon) آمن للوضع في الموقع. لا تضع المفتاح السري (secret / service_role) أبداً.

## الأمان

- كل الصلاحيات مطبّقة داخل قاعدة البيانات (Row Level Security)، وليست في الواجهة فقط:
  - الزائر غير المسجل لا يرى أي مهمة أو موظف.
  - الموظف لا يرى إلا مهامه، ولا يستطيع تعديل إلا حالتها.
  - إضافة الموظفين وتعديلهم وإعادة تعيين كلمات المرور للمدير فقط.
- كلمات المرور مشفّرة (bcrypt)، والموظف الجديد يُجبر على تغيير كلمة المرور المؤقتة عند أول دخول.
- تعطيل حساب موظف يمنعه من الدخول فوراً.

## ملاحظات

- خطة Supabase المجانية توقف المشروع مؤقتاً إذا لم يُستخدم لمدة أسبوع. عندها افتح لوحة Supabase واضغط **Restore project**.
- تشغيل كود الإعداد (`public/setup.sql`) أكثر من مرة آمن ولا يحذف أي بيانات.
